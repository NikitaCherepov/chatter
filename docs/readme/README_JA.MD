# Chatterとは？

Chatterは、サーバー上で動作し、ワンクリックで友人や家族と共有できるAIエージェントを備えたマルチプラットフォームシステムです！また、プラン、制限、便利な管理機能を備えた独自のサービスをデプロイすることもできます。

モデルの料金は自動的に取得されます。サブスクリプションの予算を設定するだけでOKです。

> **決済システムはまだ統合されていません！**

![ChatterがTelegramとDesktopを接続](../assets/chatter-telegram-desktop.gif)

AIを母親と共有したいけれど、テクノロジーが複雑すぎると思われている？Telegramボットを渡しましょう。学習曲線はゼロです。

自分のJarvisが欲しいと思ったことはありませんか？照明を点けたり、音声コマンドに応答したり、夜にはブラインドを下ろしたりするような。スマートホーム統合を接続した後、Chatterは追加のコードや無駄なトークンなしでそれを実現できます。

あるいは、単にボットとロールプレイをしたいだけで、設定を調べたり、ローカルサーバーを立ち上げたり、設定を理解したりしたくなかったのでは？Chatterは最もユーザーフレンドリーなインターフェースと便利な管理パネルを備えています（可能な限り）。

AIエージェントはサーバー（バックエンド）上で動作し、TelegramとあなたのPCを接続します。

```
Telegram <-> Backend <-> Desktop
```

Telegramユーザーは、Desktopが接続されている間、同じチャットを続けてPCを制御できます。ほとんどの機能は、メッセージがどこから送信されたかに関係なく利用できます。

---

## プロジェクトの構成は？

 - **backend-api** — Chatterのすべてのサーバー側ロジック。エージェント、ツール、メモリ、チャット、制限、ユーザー、そしてすべての共有ロジックはここにあります。
 - **desktop-app** — エージェントと通信しPCを制御するためのElectronアプリ。
 - **Telegram bot** — 同じアカウント、チャット、機能への2つ目の本格的なインターフェース。プロジェクトルートにあります（不便ですが、すべてはここから始まりました）。
 - **admin-panel** — モデル、キー、ユーザー、制限、バックアップ、サーバー状態の管理。
 - **chatter-manager** — 管理パネルをDockerに接続し、コンポーネントの起動、停止、更新を可能にします。
 - **webapp-notes** — メモ用のTelegramミニアプリ。
 - **voice-service** — オプションのローカル文字起こしと音声合成。

すべてのサーバーコンポーネントは個別のDockerコンテナで実行され、Docker Composeを介してリンクされています。そのため、実際に必要なものだけを維持できます。

## インストール方法は？

 1. サーバーをレンタルし、必ずfail2banをインストールしてください。インストーラーはUFWを自動的に設定します：サーバーの実際のSSHポートへのアクセスを保持し、Chatter用にポート80/443を開きます。
 2. コンソールを開いて実行：
    ```bash
    curl -fsSL https://raw.githubusercontent.com/NikitaCherepov/chatter/main/install.sh | sudo bash
    ```
 3. インストールの最後に表示されるログインとパスワードを**必ず**保存してください。
 4. サーバーのアドレスで管理パネルにアクセスし、コンソールに表示されたログインとパスワードを入力します。
 5. 初回起動に必要な手順を完了します：
    - Autoモード用のモデルとAPIキーを追加します。
    - Liteモード用のモデルとAPIキーを追加します。
    - [BotFather](https://t.me/BotFather)からTelegramトークンを取得し、パネルに追加します。
    - オプションで、パネルで提供されるWebapp-Notesリンクをコピーしてボットに追加します。
 6. ボットにメッセージを送信し、管理パネルでプロファイルを承認してから、自分自身に管理者権限を付与します。

**完了！**

## Desktopアプリを接続するには？

 1. Releasesからアプリをダウンロードしてインストールします。Windowsはデジタル署名がないことを警告する場合があります：現在のビルドは証明書で署名されていません。
 2. 管理パネルのAccess Keysセクションに移動します。
 3. 新しいキーを作成し、Desktopアプリに貼り付けます。
 4. 登録します。

**完了！**

## PCアカウントとTelegramをリンクするには？

 1. デスクトップで設定に移動します。
 2. "Linked accounts"を選択します。
 3. "Telegram"をクリックします。
 4. Telegramボットで次のコマンドを送信します：`/link`
 5. 画面に表示されたコードを入力します。

**完了！**

## 友達と共有するには？

**Telegram経由：**
 1. Telegramボットを送信し、メッセージが来るのを待ちます。
 2. 管理パネルからアカウントを承認します。

**Desktop経由：**
 1. Desktopアプリを送信し、サーバーに接続するためのアクセスキーを共有します。

**完了！**

誰かがあなたのキーを共有したかどうかはいつでも確認でき、いつでも取り消すことができます。

## 管理パネルでできることは？

![Chatter管理パネルサーバー概要](../assets/admin-overview.png)

 1. **コンポーネントの状態を監視**し、再起動します。
 2. **新しいモデルを追加したい？** 保存済みのAPIキーを再入力したり、OpenRouter全体からモデル名を探し回ったりする必要はありません。
    - APIキーは保存して再利用できます。
    - OpenRouter用のモデル検索エンジンが管理パネルに組み込まれています。
    - プロバイダーリストはモデルを選択するとすぐに表示されます。特定のプロバイダーにのみリクエストを送りたい？ドロップダウンから選択するだけです。
    - 入力/出力/キャッシュのトークン価格はモデル選択時に自動的に設定されます。
    - Visionモデルは別途利用可能です — メインモデルがマルチモーダルでない場合、添付された画像の説明をVisionに依頼します。

    ![管理パネルでのモデル、プロバイダー、価格の選択](../assets/admin-model-selection.gif)

 3. **便利な制限管理。**
    - ユーザーが使用できる予算を設定するだけです。
    - すべてのユーザーに対して画像とウェブ検索のカスタマイズ可能な制限、さらに画像添付を無効にする機能。

    ![プラン、予算、制限の設定](../assets/admin-plans-limits.png)

 4. **分析** — ユーザーがどのモデルを使用しているか、サブエージェントが関与しているか、メッセージがどの程度キャッシュされているかなど。

    ![ユーザー統計、接続、モデル使用状況](../assets/admin-user-usage.png)

 5. バックエンドログとサーバーパフォーマンスグラフ。
 6. 利用可能なサービスの便利な統合。キーを貼り付け、データを入力するだけで、すべてがすぐに動作します。
 7. **カスタムビルド：**
    - Telegramミニアプリが不要？有効にしなければいいだけです。
    - サーバー側のTTSや音声文字起こしの容量がない？問題ありません。
    - ユーザー向けのプリセットプロンプトを好きなだけ設定できます。
 8. ユーザーをBANする必要がありますか？ワンクリックで、TelegramとDesktopアプリを通じたサーバーへのアクセスを即座に失います。アクセスキーもいつでも取り消せます。

## Chatterにできることは？

 1. ベクターメモリを使用。各ユーザーはデフォルトで分離された個別のレコードを取得します。現在は[Pinecone](https://app.pinecone.io/)統合のみ利用可能です。
 2. "Alexa"、"Hey, Jarvis"、"Hey Mycroft"、"Hey Rhasspy"でウェイクアップ、音声認識と音声応答をサポート。

    ![Chatterの音声起動とUI制御](../assets/chatter-voice-activation.gif)

 3. Desktopアプリに組み込み：
    - ローカルPiperモデル（TTS用）；
    - ネイティブChrome TTSモデル；
    - [Cartesia](https://www.cartesia.ai/)統合。
 4. PC上でコマンドを実行、ファイルの編集と読み取り。CLIとして使用可能。

    ![Chatterが自分でウェブサイトを作成して開く](../assets/chatter-site-creation.gif)

 5. 追加したメールボックスからメールを読み取り、送信。現在、[Gmail](https://mail.google.com/mail/)と[Yandex](https://mail.yandex.ru/)、および手動設定可能なその他のメールに対応した便利なガイド付き統合が利用可能です。メールの送信にはユーザーの確認が必要です。
 6. [Tavily](https://www.tavily.com/)サービスを使用したウェブ検索。
 7. [Browserless](https://www.browserless.io/pricing)を使用したウェブサイトの読み取りと解析。
 8. 参照画像またはテキストからOpenRouter経由で画像生成。
 9. 任意のタスクにサブエージェントを使用。

    ![Chatterの並列サブエージェント動作](../assets/chatter-parallel-subagents.gif)

 10. 専門エージェントの呼び出し。例：動画の圧縮や他フォーマットへの変換。
 11. サーバーの管理。ボットはあなたのSSHキーやsudoパスワードを見ることはありません。コマンド実行のため、SSHセッションはサーバー上で直接開かれます。SSHキーはワンボタンでコンピューターから直接取得できます。
 12. Runbook手順を保存して後で使用したり、他の人と共有したりできます。
 13. ドラマチックな制御用のマクロを保存（*Alexa、仕事の時間だよ！*）。
 14. カスタムプロンプト、さらに便利な編集のためのパネル内蔵のAIエディター。
 15. タスクとリマインダーの設定。例：照明を点ける、1ヶ月後に目薬を捨てるようリマインドする、寝ている間にサーバーをチェックする（許可リストにあるコマンドのみ）。
 16. ピクセルアバターを制御し、会話に合わせてそのムードを画面上で調整。インターネットで見つけた画像やGIFも表示できます。
 17. ピクセルアートを作成し、ピクセルアバターに直接出力。
 18. チャットをDOCXとして保存、チャットからリンクされたTelegramアカウントに直接メッセージを送信、その他多数のQuality of Life機能。
 19. ボットとのロールプレイが好きですか？**Dice Mode**が組み込まれており、送信するメッセージごとにd20を振ってストーリーに影響を与えます！
 20. アプリインターフェースに組み込まれたマップの制御、マップ上のポイントの記憶、ルートのプロット（ただし情報は再確認してください！）。
 21. Telegramアプリからもアクセス可能なノートブックにメモを保存。
 22. コンテキストサイズの設定、設定に触れずにサブエージェント用モデルの便利な選択、推論レベルの設定（現在OpenRouter、DeepSeek、Xiaomiプロバイダーで利用可能）。
 23. Desktop接続中にウェブカメラの制御、スクリーンショットの撮影、画面のクリック。このようなアクションにはすべて確認が必要です。
 24. ほとんどの機能は、便利なメニューとインラインボタンでTelegramからアクセス可能。
 25. スマートホームの制御とスケジュールによる照明の点灯。Yandex統合が利用可能。Zigbeeサポートは現在実験的で、さらなるテストが必要です。
 26. ビジョンがないモデルにもドキュメントや写真を添付（ビジョンモデルが別途設定されている場合）。
 27. Telegramからの音声メッセージを文字起こし！（最低2コア、2 GB RAM、voice-apiが有効なパワフルなサーバーが必要）
 28. チャットブランチの便利で迅速な作成、指示付き再生成。
 29. ボットがコマンドを提案したが、何をするのかわからない？Reviewボタンを押すと、Liteモデルがそのリスクを評価します。

## Chatterが重視していることは？

### 1. 安全なエージェント操作

 - サーバー/PCのすべてのアクションは、ユーザーの承認がある場合のみ許可されます。例外：Yoloモード有効、Allow Always、または"このフォルダで作業"。"このフォルダで作業"は最も近い`.git`を見つけてデフォルトとして提案します。
 - エージェントはあなたのSSHキーやパスワードを決して見ません：それらは自動的に代入され、暗号化されて保存されます。エージェントにパスワードを**渡さないで**ください。たとえ要求されてもです。サーバーに新しいユーザーを作成するための別のコマンドがあります！
 - デスクトップでは、安全のために機能を選択的に無効にできます。読み取りのみ許可して書き込みを禁止したり、サブエージェント、インターネット、PCコマンドを無効にしたりできます。またはメモリへのアクセスを完全に遮断することもできます。
 - メール、SSHキー、機密データは暗号化されます。
 - 管理パネルへのすべてのAPIリクエストはリバースプロキシとChatter Managerを通過し、繰り返しのログイン試行は自動的にブロックされます。
 - 基本的なプロンプトインジェクション保護が組み込まれています。
 - ニューラルネットワークが提案したコマンドが何をするかわからない場合、Reviewを押すと別のニューラルネットワークがそれを説明し、リスクを評価します。

    ![実行前のコマンドリスクチェック](../assets/chatter-command-review.gif)

### 2. 絶え間ない最適化

 - システムプロンプトやその他の繰り返されるコンテキスト部分は安定したままなので、プロバイダーは入力トークンの最大90〜95%をキャッシュできます。
 - チャット、写真、メッセージは動的に読み込まれ、DOMの過負荷を回避します。仮想化は使用していません（嫌いだからです）：代わりに、「さらに読み込む」ボタンと文字数ベースの計算を使用しています。
 - OpenRouterは異なるプロバイダーにリダイレクトしてキャッシュを壊しますが、設定を調べてキーを構成したくない？OpenRouterから直接取得したプロバイダーを選択するだけで、そのプロバイダーのみが使用されます。
 - 複数のプロバイダー（OpenRouter/DeepSeek/Xiaomiなど）を入力でき、最初のプロバイダーがエラーで失敗した場合、タスクは即座に別のプロバイダーにリダイレクトされます。
 - 毎回ビジョンモデルを実行するお金がない？問題ありません。ビジョンモデルを一度追加すれば、メインのAIボットが添付された画像の説明をそのモデルに依頼するだけです。
 - TTSの予算はないけれど欲しい？ローカルモデルが組み込まれています。多くの外部統合も無料枠を提供しています。
 - AIが毎回ユーティリティコードを生成してトークンを消費するのを避けたい？Chatterの組み込みツールは事前にコードで実装されています。欠点のように見えますか？でもこの方法なら、主要サービスのサブスクリプションと並行して、コンピューターで`git clone`するだけでChatterに取り組むことができます（必要なら）。
 - 通常モードのDesktopアプリは約300 MBのRAMを使用し、CPUをほとんど消費しません。サーバーコンテナは別途カウントされ、TTSとWhisperは当然より多くのリソースを必要とします。比較のために：Codexは私のマシンで数十ギガバイトに膨れ上がることがありました — ちょっとした皮肉は許してください :)
 - キャッシュを壊さないように、コンテキストがあふれた場合、会話の50%がアーカイブされます（圧縮のための短い要約は将来追加予定）。
 - ドキュメントが収まらない場合、Chatterは自動的にその内容をトリミングし、選択されたコンテキスト制限の最大90%を維持します。
 - 専用のLiteモデルが、チャットタイトル、レビュー、その他の軽量リクエストの生成に使用されます。

### 3. 利便性

 - AIが生成した画像やメッセージをTelegramに転送してスマートフォンで見たい？ワンボタンで完了。
 - プロンプトを改善したい？ワンボタンでAIが提案する変更を適用できます。
 - マクロを入力したりノートブックに何かを書いたりしたくない？AIに任せましょう。
 - PC全体からSSHキーを探したくない？ワンボタンで完了 :D
 - 家を出て、スマートフォンから会話を続けたい？すべてのチャット、プロンプト選択、モデル選択がTelegramから直接利用できます！
 - APIキーを再び探し回ったり、OpenRouterでモデルを選んだり、新しいモデルの推論を解析する方法を理解したりしたくない？APIキーは保存でき、モデルは自動的に取得され、コスト、コンテキスト制限、キャッシュを維持するための利用可能なプロバイダーを即座に表示します！そしてDeepSeekとXiaomiはサードパーティプロバイダーとしてコード化されています（Mistralのような新しいものが現れたら — 私に連絡してください、追加します）。
 - 各モデルのコストを手動で計算したくない？OpenRouterは自身の値を入力し、他のモデル用のプリセットもあります。
 - ユーザーがモデル選択に悩みたくない？Autoモードが常にあります！
 - すべての統合は後日説明とクイックスタートガイドを取得予定です。スマートホーム統合用には既に存在します。

### 4. カスタマイズ

 - 各モデルのパラメータは設定可能。Temperature、Top Pなど。
 - Desktopアプリの機能は無効化およびカスタマイズ可能。

## プロジェクトをあなたの言語に翻訳する

プロジェクトをあなたの言語に翻訳することにしましたか？簡単で素早くできます：

 1. あなたの言語を`shared/languages.ts`に追加します — これはすべてのコンポーネントにおける言語リストの唯一の情報源です。
 2. 以下を実行：
    ```bash
    npm run sync:languages
    ```
    リストのローカルコピーを更新します。
 3. `.env.i18n`にAPIキーを追加：
    ```
    I18N_TRANSLATE_API_URL=url
    I18N_TRANSLATE_API_KEY=your_key
    I18N_TRANSLATE_MODEL=your_model
    ```
 4. 以下を実行：
    ```bash
    npm run i18n:translate:all
    ```
    このコマンドは、Telegramボット、Desktop、Backend API、Webapp Notes、管理パネル、changelogファイルを個別に翻訳します。
 5. お楽しみください。

## 重要

 - サービスにはまだ私が見つけていないバグが含まれている可能性があります。見つけた場合はIssuesに提出してください。一緒に解決しましょう。既に把握しているバグは修正バックログにあります。プロジェクトは一人で進めているので、助けは大歓迎です！
 - 今後の計画には、desktop-appとbackend-apiの両方のリファクタリングが含まれています。
 - Chatterを仕事でCLIとして使用する場合、まだ問題が発生する可能性があります（例：文字列を混同したり、型をチェックせずにエラーを残したりするなど）。これについては改善に取り組んでいます。
