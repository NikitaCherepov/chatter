# Chatter란 무엇인가요?

Chatter는 서버에서 실행되는 AI 에이전트를 갖춘 멀티플랫폼 시스템으로, 친구나 가족과 한 번의 클릭으로 공유할 수 있습니다! 또한 플랜, 제한, 편리한 관리 기능을 갖춘 자체 서비스를 배포할 수도 있습니다.

모델 가격은 자동으로 가져옵니다. 구독 예산만 설정하면 됩니다.

> **결제 시스템은 아직 통합되지 않았습니다!**

![Chatter가 Telegram과 Desktop을 연결](../assets/chatter-telegram-desktop.gif)

AI를 엄마와 공유하고 싶지만 기술이 너무 복잡하다고 생각하시나요? Telegram 봇을 알려주세요. 학습 곡선이 전혀 없습니다.

불을 켜고, 음성 명령에 응답하고, 밤에는 블라인드를 내리는 나만의 Jarvis를 원하셨나요? 스마트 홈 통합을 연결한 후, Chatter는 추가 코드나 낭비되는 토큰 없이 이를 수행할 수 있습니다.

아니면 그냥 봇과 롤플레이를 하고 싶었지만 설정을 뒤지고, 로컬 서버를 띄우고, 설정을 파악하는 데 시간을 쏟고 싶지 않으셨나요? Chatter는 가장 사용자 친화적인 인터페이스와 편리한 관리자 패널을 갖추고 있습니다 (가능한 한).

AI 에이전트는 서버(백엔드)에서 실행되며 Telegram과 PC를 연결합니다.

```
Telegram <-> Backend <-> Desktop
```

Telegram 사용자는 Desktop이 연결되어 있는 동안 동일한 채팅을 계속하고 PC를 제어할 수 있습니다. 대부분의 기능은 메시지가 어디서 전송되었는지에 관계없이 사용할 수 있습니다.

---

## 프로젝트 구조는 어떻게 되나요?

 - **backend-api** — Chatter의 모든 서버 측 로직. 에이전트, 도구, 메모리, 채팅, 제한, 사용자 및 모든 공유 로직이 여기에 있습니다.
 - **desktop-app** — 에이전트와 통신하고 PC를 제어하기 위한 Electron 앱.
 - **Telegram bot** — 동일한 계정, 채팅 및 기능에 대한 두 번째 본격적인 인터페이스. 프로젝트 루트에 있습니다 (불편하지만, 모든 것이 여기서 시작되었습니다).
 - **admin-panel** — 모델, 키, 사용자, 제한, 백업 및 서버 상태 관리.
 - **chatter-manager** — 관리자 패널을 Docker에 연결하여 구성 요소를 시작, 중지 및 업데이트할 수 있습니다.
 - **webapp-notes** — 메모용 Telegram 미니 앱.
 - **voice-service** — Telegram 전용 선택 서비스입니다. 수신한 음성 메시지를 텍스트로 변환하고, 사용자가 음성 메시지를 보내면 Chatter의 답변을 자동으로 음성으로 읽어 줍니다.

모든 서버 구성 요소는 별도의 Docker 컨테이너에서 실행되며 Docker Compose를 통해 연결됩니다. 따라서 실제로 필요한 것만 유지할 수 있습니다.

## 설치 방법은?

 1. 서버를 임대하고 fail2ban을 반드시 설치하세요. 설치 프로그램이 UFW를 자동으로 구성합니다: 서버의 실제 SSH 포트에 대한 액세스를 유지하고 Chatter용으로 포트 80/443을 엽니다.
 2. 콘솔을 열고 실행:
    ```bash
    curl -fsSL https://raw.githubusercontent.com/NikitaCherepov/chatter/main/install.sh | sudo bash
    ```
 3. 설치 종료 시 표시되는 로그인과 비밀번호를 **반드시** 저장하세요.
 4. 서버 주소로 관리자 패널에 접속하여 콘솔에 표시된 로그인과 비밀번호를 입력하세요.
 5. 첫 실행에 필요한 단계를 완료하세요:
    - Auto 모드용 모델 및 API 키를 추가합니다.
    - Lite 모드용 모델 및 API 키를 추가합니다.
    - [BotFather](https://t.me/BotFather)에서 Telegram 토큰을 받아 패널에 추가합니다.
    - 선택 사항으로, 패널에서 제공된 Webapp-Notes 링크를 복사하여 봇에 추가합니다.
 6. 봇에 메시지를 보내고 관리자 패널에서 프로필을 승인한 후, 자신에게 관리자 권한을 부여하세요.

**완료!**

## Desktop 앱을 연결하는 방법은?

 1. Releases에서 앱을 다운로드하여 설치하세요. Windows에서 디지털 서명이 없다고 경고할 수 있습니다: 현재 빌드는 인증서로 서명되지 않았습니다.
 2. 관리자 패널에서 Access Keys 섹션으로 이동하세요.
 3. 새 키를 생성하여 Desktop 앱에 붙여넣으세요.
 4. 등록하세요.

**완료!**

---

## PC 계정과 Telegram을 연결하는 방법은?

 1. 데스크톱에서 설정으로 이동하세요.
 2. "Linked accounts"를 선택하세요.
 3. "Telegram"을 클릭하세요.
 4. Telegram 봇에서 다음을 전송하세요: `/link`
 5. 화면에 표시된 코드를 입력하세요.

**완료!**

 2. 관리자 패널에서 계정을 승인하세요.

**Desktop을 통해:**
 1. Desktop 앱을 보내고 서버에 연결할 액세스 키를 공유하세요.

누군가가 키를 공유했는지 항상 확인할 수 있으며, 언제든지 키를 취소할 수 있습니다.

## 관리자 패널로 무엇을 할 수 있나요?

![Chatter 관리자 패널 서버 개요](../assets/admin-overview.png)

 1. **구성 요소 상태 모니터링** 및 재시작.
 2. **새 모델을 추가하고 싶으신가요?** 저장된 API 키를 다시 입력하거나 OpenRouter 전체에서 모델 이름을 찾을 필요가 없습니다.
    - API 키를 저장하고 재사용할 수 있습니다.
    - OpenRouter용 모델 검색 엔진이 관리자 패널에 내장되어 있습니다.
    - 모델을 선택하면 공급자 목록이 즉시 표시됩니다. 특정 공급자에게만 요청을 보내고 싶으신가요? 드롭다운에서 선택하기만 하면 됩니다.
    - 입력/출력/캐시 토큰 가격은 모델 선택 시 자동으로 설정됩니다.
    - Vision 모델은 별도로 사용할 수 있습니다 — 메인 모델이 멀티모달이 아닌 경우, 첨부된 이미지를 설명하도록 Vision에 요청합니다.

    ![관리자 패널에서 모델, 공급자 및 가격 선택](../assets/admin-model-selection.gif)

 3. **편리한 제한 관리.**
    - 사용자가 사용할 수 있는 예산을 설정하기만 하면 됩니다.
    - 모든 사용자에 대한 이미지 및 웹 검색의 사용자 정의 가능한 제한, 이미지 첨부를 비활성화하는 기능.

    ![플랜, 예산 및 제한 설정](../assets/admin-plans-limits.png)

 4. **분석** — 사용자가 어떤 모델을 사용하는지, 하위 에이전트가 관여하는지, 메시지가 얼마나 잘 캐시되는지 등.

    ![사용자 통계, 연결 및 모델 사용량](../assets/admin-user-usage.png)

 5. 백엔드 로그 및 서버 성능 그래프.
 6. 사용 가능한 서비스의 편리한 통합. 키를 붙여넣고 데이터를 입력하면 모든 것이 즉시 작동합니다.
 7. **사용자 정의 빌드:**
    - Telegram 미니 앱이 필요 없으신가요? 활성화하지 마세요.
    - 서버 측 TTS 및 음성 전사를 위한 용량이 부족하신가요? 문제 없습니다.
    - 사용자를 위한 사전 설정 프롬프트를 원하는 만큼 구성할 수 있습니다.
 8. 사용자를 차단해야 하나요? 한 번의 클릭으로 Telegram 및 Desktop 앱을 통한 서버 액세스가 즉시 차단됩니다. 액세스 키도 언제든지 취소할 수 있습니다.

## Chatter로 무엇을 할 수 있나요?

 1. 벡터 메모리 사용. 각 사용자는 기본적으로 분리된 개별 레코드를 얻습니다. 현재는 [Pinecone](https://app.pinecone.io/) 통합만 사용 가능합니다.
 2. "Alexa", "Hey, Jarvis", "Hey Mycroft" 또는 "Hey Rhasspy"로 깨어나기, 음성 인식 및 음성 응답 지원.

    ![Chatter 음성 활성화 및 UI 제어](../assets/chatter-voice-activation.gif)

 3. Desktop 앱에 내장:
    - 로컬 Piper 모델(TTS용);
    - 기본 Chrome TTS 모델;
    - [Cartesia](https://www.cartesia.ai/) 통합.
 4. PC에서 명령 실행, 파일 편집 및 읽기. CLI로 사용할 수 있습니다.

    ![Chatter가 스스로 웹사이트를 만들고 엽니다](../assets/chatter-site-creation.gif)

 5. 추가한 메일함에서 이메일 읽기 및 보내기. 현재 [Gmail](https://mail.google.com/mail/) 및 [Yandex](https://mail.yandex.ru/), 그리고 수동으로 구성할 수 있는 다른 모든 이메일에 대한 편리한 안내 통합이 제공됩니다. 이메일 전송에는 사용자 확인이 필요합니다.
 6. [Tavily](https://www.tavily.com/) 서비스를 통한 웹 검색.
 7. [Browserless](https://www.browserless.io/pricing)를 사용한 웹사이트 읽기 및 파싱.
 8. 참조 이미지 또는 텍스트에서 OpenRouter를 통해 이미지 생성.
 9. 모든 작업에 하위 에이전트 사용.

    ![Chatter 병렬 하위 에이전트 작업](../assets/chatter-parallel-subagents.gif)

 10. 전문 에이전트 호출. 예: 비디오 압축 및 다른 형식으로 변환.
 11. 서버 관리. 봇은 SSH 키나 sudo 비밀번호를 절대 볼 수 없습니다. 명령 실행을 위해 서버에서 직접 SSH 세션이 열립니다. SSH 키는 컴퓨터에서 한 번의 버튼으로 가져올 수 있습니다.
 12. Runbook 지침을 저장하여 나중에 사용하고 다른 사람과 공유.
 13. 극적인 제어를 위한 매크로 저장 (*Alexa, 일할 시간이야!*).
 14. 사용자 정의 프롬프트, 편리한 편집을 위한 패널 내장 AI 편집기.
 15. 작업 및 알림 설정. 예: 불 켜기, 한 달 후에 안약을 버리라고 알림, 또는 자는 동안 서버 확인 (허용 목록에 있는 명령만).
 16. 픽셀 아바타를 제어하고 대화에 맞게 분위기를 화면에서 직접 조정. 인터넷에서 찾은 이미지와 GIF도 표시.
 17. 픽셀 아트를 만들어 픽셀 아바타에 직접 출력.
 18. 채팅을 DOCX로 저장, 채팅에서 연결된 Telegram 계정으로 직접 메시지 보내기, 기타 여러 Quality of Life 기능.
 19. 봇과의 롤플레이를 좋아하시나요? **Dice Mode**가 내장되어 있어, 보내는 모든 메시지에 d20을 굴려 스토리에 영향을 미칩니다!
 20. 앱 인터페이스에 내장된 지도 제어, 지도上的 포인트 기억, 경로 표시 (하지만 정보를 다시 확인하세요!).
 21. Telegram 앱에서도 접근 가능한 노트북에 메모 저장.
 22. 컨텍스트 크기 구성, 설정을 건드리지 않고 하위 에이전트용 모델을 편리하게 선택, 추론 수준 설정 (현재 OpenRouter, DeepSeek, Xiaomi 공급자에서 사용 가능).
 23. Desktop이 연결된 동안 웹캠 제어, 스크린샷 촬영, 화면 클릭. 이러한 모든 작업에는 사용자의 확인이 필요합니다.
 24. 대부분의 기능은 편리한 메뉴와 인라인 버튼으로 Telegram에서 액세스 가능.
 25. 스마트 홈 제어 및 일정에 따른 조명 켜기. Yandex 통합 사용 가능. Zigbee 지원은 현재 실험적이며 추가 테스트가 필요합니다.
 26. 비전이 없는 모델에도 문서와 사진 첨부 (비전 모델이 별도로 설정된 경우).
 27. Telegram의 음성 메시지 전사! (최소 2코어, 2GB RAM, voice-api가 활성화된 강력한 서버 필요)
 28. 편리하고 빠른 채팅 브랜치 생성 및 지침을 통한 재생성.
 29. 봇이 명령을 제안했지만 무엇을 하는지 모르시겠나요? Review 버튼을 누르면 Lite 모델이 위험을 평가합니다.

## Chatter가 중점을 두는 것은?

### 1. 안전한 에이전트 운영

 - 모든 서버/PC 작업은 사용자 승인이 있을 때만 허용됩니다. 예외: Yolo 모드 활성화, Allow Always, 또는 "이 폴더에서 작업". "이 폴더에서 작업"은 가장 가까운 `.git`을 찾아 기본값으로 제안합니다.
 - 에이전트는 SSH 키나 비밀번호를 절대 볼 수 없습니다: 자동으로 대체되며 암호화되어 저장됩니다. 에이전트가 요청하더라도 **절대** 비밀번호를 알려주지 마세요. 서버에 새 사용자를 만드는 별도의 명령이 있습니다!
 - 데스크톱에서는 안전을 위해 기능을 선택적으로 비활성화할 수 있습니다. 읽기만 허용하고 쓰기를 금지하거나, 하위 에이전트, 인터넷 또는 PC 명령을 비활성화할 수 있습니다. 또는 메모리에 대한 액세스를 완전히 차단할 수 있습니다.
 - 이메일, SSH 키 및 민감한 데이터는 암호화됩니다.
 - 모든 관리자 패널 API 요청은 리버스 프록시와 Chatter Manager를 통과하며, 반복적인 로그인 시도는 자동으로 차단됩니다.
 - 기본적인 프롬프트 인젝션 보호 기능이 내장되어 있습니다.
 - 신경망이 제안한 명령이 무엇을 하는지 모르겠다면 Review를 누르면 다른 신경망이 이를 설명하고 위험을 평가합니다.

    ![실행 전 명령 위험 확인](../assets/chatter-command-review.gif)

### 2. 끊임없는 최적화

 - 시스템 프롬프트 및 기타 반복되는 컨텍스트 부분은 안정적으로 유지되어 공급자가 입력 토큰의 최대 90-95%를 캐시할 수 있습니다.
 - 채팅, 사진, 메시지는 DOM 과부하를 피하기 위해 동적으로 로드됩니다. 가상화는 사용하지 않습니다 (싫어합니다): 대신 "더 보기" 버튼과 문자 수 기반 계산을 사용합니다.
 - OpenRouter가 다른 공급자로 리디렉션하여 캐싱을 깨뜨리고, 설정을 파고들어 키를 구성하고 싶지 않으신가요? OpenRouter에서 직접 가져온 공급자를 선택하기만 하면 해당 공급자만 사용됩니다.
 - 여러 공급자(OpenRouter/DeepSeek/Xiaomi 등)를 입력할 수 있으며, 첫 번째 공급자가 오류로 실패하면 작업이 즉시 다른 공급자로 리디렉션됩니다.
 - 매번 비전 모델을 실행할 돈이 없으신가요? 문제 없습니다. 비전 모델을 한 번 추가하면 메인 AI 봇이 첨부한 이미지 설명을 요청할 뿐입니다.
 - TTS를 위한 예산은 없지만 여전히 원하시나요? 로컬 모델이 내장되어 있습니다. 많은 외부 통합도 무료 티어를 제공합니다.
 - AI가 매번 유틸리티 코드를 생성하여 토큰을 소모하는 것을 원하지 않으신가요? Chatter의 내장 도구는 사전에 코드로 구현되어 있습니다. 단점처럼 보이나요? 하지만 이 방법으로 주요 서비스 구독과 함께 컴퓨터에서 `git clone`만으로 Chatter 작업을 할 수 있습니다 (원한다면).
 - 일반 모드의 Desktop 앱은 약 300MB의 RAM을 사용하며 CPU를 거의 로드하지 않습니다. 서버 컨테이너는 별도로 계산되며, TTS와 Whisper는 당연히 더 많은 리소스가 필요합니다. Codex도 제 컴퓨터에서는 얼마든지 느려지고 버벅일 수 있습니다.
 - 캐싱을 깨뜨리지 않기 위해 컨텍스트가 오버플로우되면 대화의 50%가 보관됩니다 (압축을 위한 짧은 요약은 향후 추가 예정).
 - 문서가 맞지 않으면 Chatter는 자동으로 내용을 잘라내어 선택한 컨텍스트 제한의 최대 90%를 유지합니다.
 - 전용 Lite 모델이 채팅 제목, 리뷰 및 기타 가벼운 요청을 생성하는 데 사용됩니다.

### 3. 편의성

 - AI가 생성한 이미지나 메시지를 Telegram으로 전달하여 휴대폰에서 보고 싶으신가요? 버튼 하나면 됩니다.
 - 프롬프트를 개선하고 싶으신가요? 버튼 하나를 누르고 AI가 제안하는 변경 사항을 적용하세요.
 - 매크로를 작성하거나 노트북에 무언가를 쓰고 싶지 않으신가요? AI에게 요청하세요.
 - PC 전체에서 SSH 키를 찾고 싶지 않으신가요? 버튼 하나면 됩니다 :D
 - 집을 나와 휴대폰에서 대화를 계속하고 싶으신가요? 모든 채팅, 프롬프트 선택 및 모델 선택이 Telegram에서 바로 가능합니다!
 - API 키를 다시 찾아 헤매거나, OpenRouter에서 모델을 고르거나, 새 모델의 추론을 분석하는 방법을 파악하고 싶지 않으신가요? API 키를 저장할 수 있고, 모델은 자동으로 가져와지며 비용, 컨텍스트 제한 및 캐싱을 유지하기 위한 사용 가능한 공급자를 즉시 표시합니다! 그리고 DeepSeek와 Xiaomi는 서드파티 공급자로 코딩되어 있습니다 (Mistral과 같은 새로운 것이 나타나면 — 저에게 연락 주세요, 추가하겠습니다).
 - 각 모델의 비용을 수동으로 계산하고 싶지 않으신가요? OpenRouter가 자체 값을 입력하고 다른 모델용 프리셋도 있습니다.
 - 사용자들이 모델 선택에 신경 쓰고 싶지 않아하나요? Auto 모드가 항상 있습니다!
 - 모든 통합은 나중에 설명과 퀵스타트 가이드를 받게 됩니다. 스마트 홈 통합용은 이미 존재합니다.

## 프로젝트를 사용자의 언어로 번역하기

프로젝트를 사용자의 언어로 번역하기로 결정하셨나요? 빠르고 쉽습니다:

 1. `shared/languages.ts`에 사용자의 언어를 추가하세요 — 이것은 모든 구성 요소에서 언어 목록의 단일 정보 소스입니다.
 2. 다음을 실행:
    ```bash
    npm run sync:languages
    ```
    목록의 로컬 복사본을 업데이트합니다.
 3. `.env.i18n`에 API 키를 추가:
    ```
    I18N_TRANSLATE_API_URL=url
    I18N_TRANSLATE_API_KEY=your_key
    I18N_TRANSLATE_MODEL=your_model
    ```
 4. 다음을 실행:
    ```bash
    npm run i18n:translate:all
    ```
    이 명령은 Telegram 봇, Desktop, Backend API, Webapp Notes, 관리자 패널 및 변경 로그 파일을 별도로 번역합니다.
 5. 즐기세요.
