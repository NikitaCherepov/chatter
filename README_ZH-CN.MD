# 什么是 Chatter？

Chatter 是一个多平台系统，配备 AI 智能体，运行在服务器上，一键即可与朋友或家人分享！您还可以在其上部署自己的服务，支持套餐、限制和便捷管理。

模型价格自动获取。您只需为订阅设置预算即可。

> **支付系统尚未集成！**

![Chatter 连接 Telegram 和 Desktop](docs/assets/chatter-telegram-desktop.gif)

想和妈妈分享 AI，但她觉得技术太复杂？给她你的 Telegram 机器人。零学习成本。

想要自己的 Jarvis，能开灯、响应语音指令、晚上自动放下百叶窗？连接智能家居集成后，Chatter 可以在无需额外代码或浪费 token 的情况下完成这一切。

或者，你只是想和机器人进行角色扮演，但不想深究配置文件、启动本地服务器、研究各种设置？Chatter 拥有最友好的用户界面和便捷的管理面板（尽可能做到了最好）。

AI 智能体运行在服务器（后端）上，将 Telegram 和你的电脑连接在一起。

```
Telegram <-> Backend <-> Desktop
```

Telegram 用户可以在 Desktop 连接的情况下继续相同的对话并控制他们的电脑。无论消息从哪里发送，大部分功能都可使用。

## 项目结构是怎样的？

- **backend-api** — Chatter 的所有服务器端逻辑。智能体、工具、记忆、聊天、限制、用户以及所有共享逻辑都在这里。
- **desktop-app** — 用于与智能体通信和控制电脑的 Electron 应用程序。
- **Telegram bot** — 同一账户、聊天和功能的第二个全功能界面。位于项目根目录（不太方便，但这就是一切的起点）。
- **admin-panel** — 管理模型、密钥、用户、限制、备份和服务器状态。
- **chatter-manager** — 将管理面板连接到 Docker，允许您启动、停止和更新组件。
- **webapp-notes** — 用于笔记的 Telegram 小程序。
- **voice-service** — 可选的本地转录和语音合成。

所有服务器组件都在独立的 Docker 容器中运行，并通过 Docker Compose 连接。因此你可以只保留真正需要的内容。

## 如何安装？

1. 租用一台服务器，并确保在其上安装 fail2ban。安装程序会自动配置 UFW：它将保留对服务器实际 SSH 端口的访问，并为 Chatter 打开 80/443 端口。
2. 打开控制台并运行：
   ```bash
   curl -fsSL https://raw.githubusercontent.com/NikitaCherepov/chatter/main/install.sh | sudo bash
   ```
3. **务必**保存安装结束时显示的登录名和密码。
4. 通过服务器地址进入管理面板，输入控制台中显示的登录名和密码。
5. 完成首次启动所需的步骤：
   - 添加 Auto 模式的模型和 API 密钥。
   - 添加 Lite 模式的模型和 API 密钥。
   - 从 [BotFather](https://t.me/BotFather) 获取 Telegram token 并将其添加到面板。
   - （可选）复制面板中提供的 Webapp-Notes 链接并将其添加到你的机器人。
6. 给机器人发送消息，通过管理面板批准你的个人资料，然后授予自己管理员权限。

**完成！**

## 如何连接 Desktop 应用程序？

1. 从 Releases 下载应用程序并安装。Windows 可能会警告缺少数字签名：目前构建版本未使用证书签名。
2. 进入管理面板中的"访问密钥"部分。
3. 创建一个新密钥并将其粘贴到 Desktop 应用程序中。
4. 注册。

**完成！**

## 如何将 PC 账户与 Telegram 关联？

1. 在桌面上进入设置。
2. 选择"关联账户"。
3. 点击"Telegram"。
4. 在 Telegram 机器人中发送：`/link`
5. 输入屏幕上显示的代码。

**完成！**

## 如何与朋友分享？

**通过 Telegram：**
1. 将 Telegram 机器人发送给他们，等待他们发消息。
2. 从管理面板批准他们的账户。

**通过 Desktop：**
1. 将 Desktop 应用程序发送给他们，并分享一个访问密钥用于连接你的服务器。

**完成！**

你可以随时查看是否有人分享了你的密钥，并且可以随时撤销它。

## 管理面板能做什么？

![Chatter 管理面板服务器概览](docs/assets/admin-overview.png)

1. **监控组件状态**并重新启动它们。
2. **想添加新模型？** 无需重新输入已保存的 API 密钥，也无需浏览整个 OpenRouter 搜索模型名称。
   - API 密钥可以保存并重复使用。
   - 管理面板内置了 OpenRouter 的模型搜索引擎。
   - 选择模型后，提供商列表会自动填充。希望请求只发送给特定提供商？只需从下拉菜单中选择即可。
   - 选择模型时，输入/输出/缓存 token 价格会自动设置。
   - Vision 模型单独提供——如果主模型不是多模态的，它会请 Vision 描述你附上的图片。

   ![在管理面板中选择模型、提供商和价格](docs/assets/admin-model-selection.gif)

3. **便捷的限额管理。**
   - 只需设置用户可用的预算。
   - 可为所有用户自定义图片和网络搜索的限制，还可以禁用图片附件。

   ![设置套餐、预算和限制](docs/assets/admin-plans-limits.png)

4. **分析**用户正在使用哪些模型、是否涉及子智能体、消息缓存效果如何等等。

   ![用户统计、连接和模型使用情况](docs/assets/admin-user-usage.png)

5. 后端日志和服务器性能图表。
6. 便捷地集成可用服务。粘贴密钥，输入数据，一切立即可用。
7. **自定义构建：**
   - 不想要 Telegram 小程序？不要启用它。
   - 没有能力运行服务器端 TTS 和语音转录？没问题。
   - 你可以根据需要为用户配置任意数量的预设提示词。
8. 需要封禁用户？一键操作，他们将立即失去通过 Telegram 和 Desktop 应用程序访问你服务器的权限。访问密钥也可以随时撤销。

## Chatter 能做什么？

1. 使用向量记忆。默认情况下，每个用户获得独立的隔离记录。目前仅支持 [Pinecone](https://app.pinecone.io/) 集成。
2. 通过"Alexa"、"Hey, Jarvis"、"Hey Mycroft"或"Hey Rhasspy"唤醒，支持语音识别和语音回复。

   ![Chatter 语音激活和 UI 控制](docs/assets/chatter-voice-activation.gif)

3. 内置到 Desktop 应用程序中：
   - 用于 TTS 的本地 Piper 模型；
   - 原生 Chrome TTS 模型；
   - [Cartesia](https://www.cartesia.ai/) 集成。
4. 在 PC 上执行命令，以及编辑和读取文件。可用作 CLI。

   ![Chatter 自主创建并打开网站](docs/assets/chatter-site-creation.gif)

5. 读取和发送已添加邮箱的电子邮件。目前，[Gmail](https://mail.google.com/mail/) 和 [Yandex](https://mail.yandex.ru/) 提供便捷的引导式集成，其他邮箱也可以手动配置。发送邮件需要用户确认。
6. 通过 [Tavily](https://www.tavily.com/) 服务使用网络搜索。
7. 使用 [Browserless](https://www.browserless.io/pricing) 读取和解析网站。
8. 通过 OpenRouter 根据参考图或文本生成图片。
9. 使用子智能体处理任何任务。

   ![Chatter 并行子智能体工作](docs/assets/chatter-parallel-subagents.gif)

10. 调用专门的智能体。例如：压缩视频并将其转换为其他格式。
11. 管理你的服务器。机器人永远不会看到你的 SSH 密钥或 sudo 密码。执行命令时，SSH 会话会直接在你的服务器上打开。SSH 密钥可以通过一个按钮直接从你的电脑获取。
12. 保存 Runbook 指令供以后使用，并与他人共享。
13. 保存宏以实现戏剧性控制（*Alexa，该工作了！*）。
14. 自定义提示词，外加内置在面板中的 AI 编辑器，方便编辑。
15. 设置任务和提醒。例如：开灯，提醒你一个月后丢弃眼药水，或者在你睡觉时检查服务器（仅当命令在允许列表中时）。
16. 控制你的像素头像，根据对话实时调整其情绪并显示在屏幕上。还可以显示它在互联网上找到的任何图片和 GIF。
17. 创建像素画并直接输出到像素头像上。
18. 将聊天保存为 DOCX，将聊天中的消息直接发送到关联的 Telegram 账户，以及许多其他 Quality of Life 功能。
19. 喜欢与机器人进行角色扮演？**Dice Mode** 已内置，每次发送消息时掷一个 d20，影响故事发展！
20. 控制应用程序界面中内置的地图，记住地图上的点，规划路线（但请复核信息！）。
21. 将笔记保存到笔记本中，也可通过 Telegram 应用程序访问。
22. 配置上下文大小，方便地为子智能体选择模型而无需修改配置文件，设置推理级别（目前适用于 OpenRouter、DeepSeek 和 Xiaomi 提供商）。
23. 控制网络摄像头，截取屏幕截图，以及在 Desktop 连接时点击屏幕。任何此类操作都需要你的确认。
24. 大部分功能可通过 Telegram 的便捷菜单和内联按钮访问。
25. 控制智能家居并按计划开灯。Yandex 集成可用；Zigbee 支持目前处于实验阶段，需要进一步测试。
26. 即使是没有 vision 的模型也能附加文档和照片（当 vision 模型单独设置时）。
27. 转录来自 Telegram 的语音消息！（需要性能强劲的服务器，至少 2 核、2 GB RAM，并启用 voice-api）
28. 方便快速地创建聊天分支，以及带指令的重新生成。
29. 机器人建议了一条命令，但不知道它做什么？按下 Review 按钮，Lite 模型会评估其风险。

## Chatter 专注于什么？

### 1. 安全的智能体操作

- 每个服务器/PC 操作仅在用户批准后才允许执行。例外情况：启用了 Yolo mode、Allow Always 或"在此文件夹中工作"。"在此文件夹中工作"会找到最近的 `.git` 并将其建议为默认文件夹。
- 智能体永远不会看到你的 SSH 密钥或密码：它们会自动替换并加密存储。**不要**将你的密码交给智能体，即使它索要也不行。它有一个单独的命令可以在服务器上创建新用户！
- 在桌面上，你可以有选择地禁用功能以确保安全。你可以禁止写入数据，只允许读取，禁用子智能体、互联网或 PC 命令。或者完全切断它对记忆的访问。
- 电子邮件、SSH 密钥和敏感数据都已加密。
- 所有管理面板 API 请求都通过反向代理和 Chatter Manager，重复的登录尝试会被自动阻止。
- 内置基本的提示注入保护。
- 如果你不知道神经网络建议的命令做什么，按下 Review，另一个神经网络会向你解释，并评估风险。

   ![执行前检查命令风险](docs/assets/chatter-command-review.gif)

### 2. 不懈的优化

- 系统提示词和其他重复的上下文部分保持稳定，以便提供商可以缓存高达 90-95% 的输入 token。
- 聊天、照片和消息动态加载，以避免 DOM 过载。不使用虚拟化（我讨厌它）：而是使用"加载更多"按钮和基于字符数的计算。
- OpenRouter 将你重定向到不同的提供商并破坏缓存，而你不想深入研究配置密钥？只需选择直接从 OpenRouter 拉取的提供商，将仅使用该提供商。
- 你可以添加多个提供商（OpenRouter/DeepSeek/Xiaomi 等），如果第一个出错，任务会立即重定向到另一个。
- 没有钱每次都运行 vision 模型？没问题。只需添加一次 vision 模型，你的主 AI 机器人就会请它描述你附上的图片。
- 没有钱用 TTS 但仍然想要？内置了本地模型。许多外部集成也提供免费套餐。
- 不想让 AI 反复为自己生成工具代码而每次浪费 token？Chatter 的内置工具已预先在代码中实现。这看起来像是个缺点，对吧？但这样你就可以在订阅主要服务的同时，通过在你的电脑上执行 `git clone` 来开发 Chatter（如果你想的话）。
- Desktop 应用程序在正常模式下使用约 300 MB RAM，几乎不消耗 CPU。服务器容器单独计算，而 TTS 和 Whisper 自然需要更多资源。作为对比：Codex 在我的机器上可能膨胀到几十 GB —— 忍不住吐槽一下 :)
- 为了避免破坏缓存，当上下文溢出时，50% 的对话会被归档（未来会添加用于压缩的简短摘要）。
- 如果文档放不下，Chatter 会自动裁剪其内容，保留所选上下文限制的 90%。
- 专用的 Lite 模型用于生成聊天标题、审查和其他轻量级请求。

### 3. 便捷性

- 想将 AI 生成的图片或消息转发到你的 Telegram 以便在手机上查看？按一个按钮。
- 想改进提示词？按一个按钮，应用 AI 建议的更改。
- 不想填写宏或在笔记本中写东西？让 AI 来做。
- 不想在整个电脑上搜索你的 SSH 密钥？按一个按钮 :D
- 离开家后想从手机继续对话？所有聊天、提示词选择和模型选择都可以直接从 Telegram 使用！
- 不想费力地再次寻找你的 API 密钥、在 OpenRouter 上挑选模型，或弄清楚如何解析新模型的推理过程？API 密钥可以保存，模型会自动拉取并立即显示成本、上下文限制和可用提供商以保持缓存！DeepSeek 和 Xiaomi 已编码为第三方提供商（如果出现像 Mistral 这样的新提供商——请告诉我，我会添加它们）。
- 不想手动计算每个模型的成本？OpenRouter 会填写自己的数值，其他模型也有预设。
- 你的用户不想费心选择模型？Auto 模式随时可用！
- 所有集成后续都会获得描述和快速入门指南。智能家居集成已经有这些了。

### 4. 可定制性

- 每个模型的参数都可以配置。温度、Top P 等。
- Desktop 应用程序的功能可以禁用和自定义。

## 将项目翻译成你的语言

决定将项目翻译成你的语言？这又快又简单：

1. 将你的语言添加到 `shared/languages.ts` —— 这是所有组件中语言列表的唯一真实来源。
2. 运行：
   ```bash
   npm run sync:languages
   ```
   以更新语言列表的本地副本。
3. 将你的 API 密钥添加到 `.env.i18n`：
   ```
   I18N_TRANSLATE_API_URL=url
   I18N_TRANSLATE_API_KEY=your_key
   I18N_TRANSLATE_MODEL=your_model
   ```
4. 运行：
   ```bash
   npm run i18n:translate:all
   ```
   该命令将分别翻译 Telegram 机器人、Desktop、Backend API、Webapp Notes、管理面板和更新日志文件。
5. 享受吧。
